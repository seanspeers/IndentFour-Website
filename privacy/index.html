Local by design

Indent Four Privacy Policy

Effective August 27, 2026

Indent Four is designed as a local Python workspace. The developer does not operate an account system, analytics service, advertising service, tracking system, or cloud execution service for the app.

Privacy policy

Information collected by the developer

The developer does not collect data from the Indent Four app. The app does not send scripts, console output, local files, contacts, calendars, reminders, location, clipboard contents, photos, identifiers, or usage information to the developer.

Data stored on your device

Scripts, examples, settings, temporary working data, and generated outputs are stored in app-controlled locations on your device. Scripts and user-facing files are available through the Indent Four folder in Files. You can remove this information by deleting the relevant files or deleting the app, subject to normal iOS and iCloud backup behavior.

Permissions and device features

A script may use Indent Four’s device module to request access to location, calendars, reminders, contacts, local notifications, system file and photo pickers, clipboard text, sharing, speech, haptics, Keychain, or device information. Protected permissions are requested only when a running script explicitly calls the corresponding feature. Importing the device module does not itself request protected access.

Network requests made by scripts

The Python runtime and included libraries can make network requests. These requests occur only when a user runs code that initiates them, such as a script that calls an API or opens a WebSocket. The destination, data sent, and response are determined by that script and the service it contacts. Review code before running it and do not include private information unless you trust the destination.

Shortcuts

Indent Four provides App Intents that let Apple Shortcuts run a saved script or inline Python code. Values and selected files are passed through Apple’s Shortcuts and App Intents systems. Temporary working files are kept in app-controlled containers and are removed after use where applicable.

Third-party software and services

Indent Four includes open-source Python and supporting libraries. These libraries run as part of the app and do not independently provide the developer with analytics or tracking data. A user-run script may communicate with a third-party service, in which case that service’s privacy practices apply.

Website hosting

The Indent Four website is hosted using GitHub Pages. GitHub may process technical information needed to deliver the site under its own privacy statement. This website does not add analytics, advertising, tracking pixels, or marketing cookies.

Children’s privacy

Indent Four is a general-purpose programming tool and is not directed specifically to children. The developer does not knowingly collect personal information from children through the app.

Changes to this policy

This policy may be updated when the app or its data practices change. The effective date at the top of this page will identify the latest version.

Contact

For privacy questions, contact the developer using the support address published on this site.
