Help + troubleshooting

Indent Four Support

Need help with a script, file, permission, or Shortcut? Start with the quick checks below. If the problem continues, send the details listed under Contact.

Support guide

Quick checks

A script will not run

Check the console for the Python exception and line number. Confirm that the file is saved and that any required input files still exist beside the script.

An output file is missing

Save outputs beside the running script using Path(__file__).with_name(...). New or changed files then appear in the console’s Output section and in Files.

A protected feature is unavailable

Location, calendars, reminders, contacts, and notifications require system permission when a script first uses them. Review access under Settings → Privacy & Security or the Indent Four entry in Settings.

A script does not appear in Shortcuts

Open Indent Four once after installation, confirm that the script is saved under the Scripts folder, then reopen the action’s script picker in Shortcuts.

An included example was deleted

Open Indent Four → Settings → Restore Included Examples. Existing files are not overwritten.

A library cannot be imported

Open Libraries inside Indent Four to see the packages included with the installed version. Version 1.0 does not install packages from external repositories.

Where files live

Scripts and their adjacent files are available in Files under On My iPhone or On My iPad → Indent Four → Scripts.

Contact

If the issue continues, email support with your device model, iOS or iPadOS version, Indent Four version, the name of the example or feature involved, and the exact console error. Remove private data, credentials, and personal files before sending.
